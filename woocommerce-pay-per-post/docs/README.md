# Pay For Post with WooCommerce documentation

Pay For Post with WooCommerce sells access to posts, pages and custom post types through WooCommerce. A visitor buys a product; the content it protects unlocks for their account.

This documentation covers version 3.4.0. It needs WordPress 6.6, WooCommerce 6.9 and PHP 7.4 or later. Features that need the Premium version are marked **(Premium)**.
